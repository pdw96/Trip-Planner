# 예산을 지도 칸에서 빼서 따로 보기 (#88)

2026-11-23. 작은 변경이라 짧은 설계로 쓴다. DB·서버 동작 변경 없음, 화면 배치만 바뀐다.

## 왜

사용자(2026-11-23): 휴대폰에서 예산이 아래 떠 있는 줄과 지도 칸 카드 두 곳에 함께 보여 불편하다. 예산이 왜 지도 칸 안에 있는지도 의문이다.

- 목표: 예산을 지도 칸에서 꺼내 독립된 칸으로 둔다. 휴대폰에서 같은 예산이 한 화면에 두 번 보이지 않는다. 고른 날(`useSelectedDay`) 연동은 그대로.
- 하지 않는 것: 예산 카드 안 내용·계산·양식 변경, 사람별 예산(#89), 새 주소(하위 화면).
- 실패로 볼 것: 날짜를 바꿀 때 보던 예산 칸이 화면 밖으로 튀어 나가는 것, 숨은 아래 줄에 키보드 초점이 들어가는 것.

## 접근 (사용자가 A 를 고름)

- **A. 같은 화면 맨 아래 예산 칸 (고름).** 지도 칸에서 빼서 일정 다음에 둔다. 아래 예산 줄은 예산 칸으로 가는 지름길이 되고, 예산 칸이 보이면 숨는다. 바꿀 범위가 가장 작고, #89 로 커져도 맨 아래에서 길어질 뿐이다.
  - PC 도 휴대폰과 똑같이 아래 예산 줄을 둔다(사용자, 2026-11-23). 처음에는 PC 에 날짜 줄 [예산] 버튼을 두기로 했다가 바꿨다. #53 에서 PC 에 줄을 두지 않은 까닭은 카드가 지도 칸 맨 위라 금방 보였기 때문인데, 카드가 맨 아래로 가면 그 까닭이 없어진다. 동작이 하나라 [예산] 버튼도 필요 없다.
- B. 화면 위 [일정·지도]/[예산] 전환 탭. 자리는 넉넉하지만 일정 줄의 예상 비용과 합계를 보려면 탭을 오가야 하고 아래 줄과 역할이 겹친다. 예산이 정말 커지면 그때 고려.
- C. `/trips/[id]/budget` 하위 화면. 고른 날이 화면 안 상태라 넘어가면 끊긴다. B 보다 나은 점이 없어 뺐다.

## 설계

배치(위에서 아래):

```
날짜 줄 [전체] ①②③ …                     ← 위에 고정
지도 칸: 지도 → 기준점 고르기 → 구간 목록   (예산 카드 빠짐)
가 볼 곳 ([전체] 에서만)
일정
예산 칸 (제목 "예산", 고른 날 따라 [전체]/[N일차] 카드)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2일차 예상 3만원 …   [+ 지출]   ← PC·휴대폰 모두. 예산 칸이 화면에 보이면 숨음
```

1. **예산 칸** (새 `budget-section.tsx` 서버 + 고른 날을 읽는 작은 클라이언트 감싸개). `loadBudget`·`toPanelBudget` 로 데이터를 받아 지금의 `BudgetCard` 를 그대로 그린다(탭 = 고른 날, 날짜 표 클릭 = `select`). 제목 `h2 "예산"`(다른 칸과 같은 `sectionTitleClass`). 지도 키가 없어도 보인다(지금과 같음). 페이지에서는 따로 `<Suspense>`.
   - 예산이 없을 때: 지금은 [전체]에서만 "예산 정하기" 빈 상태가 보이고 [N일차]에서는 카드가 사라진다. 독립 칸이 되면 [N일차]에서 맨 아래까지 내려와도 예산 자리가 비어 있게 되므로 **[N일차]에서도 빈 상태를 보인다**(Claude 판단). 예산이 없으면 아래 줄은 지금처럼 없다.
2. **지도 칸**에서 예산 카드와 예산 데이터 읽기를 뺀다(`MapSection` 의 `loadBudget`, `TripMapPanel` 의 `budget` prop).
3. **아래 예산 줄**(`budget-dock.tsx`), PC·휴대폰 모두:
   - `sm:hidden` 을 뺀다. 줄 폭은 글 칸(article) 폭을 따른다(PC 에서는 가운데 좁은 칸, 좌우 여백은 `sm:-mx-6 sm:px-6` 로 날짜 줄과 맞춤).
   - [+ 지출] 판: 휴대폰은 지금처럼 아래에서 올라오는 판. PC(`sm` 이상)에서는 화면 전체 폭으로 펼쳐지지 않게 글 칸 폭(`max-w-2xl`) 정도로 좁혀 가운데에 둔다(모양은 빌더).
   - 왼쪽 요약(글자·막대)을 누르면 예산 칸으로 내려가고 키보드 초점도 예산 칸 제목으로 옮긴다. 붙은 날짜 줄에 제목이 가리지 않게 예산 칸에 `scroll-mt` 를 둔다. 동작 줄이기(`prefers-reduced-motion`)면 부드러운 스크롤을 쓰지 않는다. [+ 지출] 은 지금처럼 판을 연다.
   - 예산 칸이 화면에 조금이라도 들어오면 줄을 숨기고, 나가면 다시 보인다. 숨은 동안 초점이 들어가지 않게(`inert` 등) 한다. 숨김·보임이 화면을 들썩이게 하지 않는다(방법은 빌더).
   - #53 설계 §5.4.2 의 "늘 떠 있다(예산 카드가 보여도 숨지 않는다)", "숫자 부분은 눌러도 아무 일 없다", "데스크톱 너비에서는 줄이 없다"를 이 규칙으로 바꾼다(사용자, 2026-11-23).
   - 휴대폰 가로 돌림 때문에 판을 `sm:hidden` 줄 밖에 둔 까닭(`budget-dock.tsx` 주석)은 줄이 모든 폭에 보이면 없어진다. 주석은 맞게 고친다.
4. **날짜를 바꿔도 예산 칸이 제자리에 있게.** 예산 칸은 일정 아래라, 날을 바꾸면(예산 표 클릭이든 날짜 줄이든) 위의 일정·가 볼 곳 높이가 바뀌어 예산 칸이 화면 밖으로 밀릴 수 있다. 날을 바꿀 때 예산 칸이 화면에 보이고 있었다면 그 위치를 유지한다. 브라우저 스크롤 고정(scroll anchoring)에만 기대지 않는다(Safari 지원이 불확실). 방법은 빌더.

- 확인: 휴대폰·PC 폭에서 브라우저로 — 예산 칸 위치, 아래 줄 숨김/다시 보임, 아래 줄 요약 누르기(마우스·키보드), PC 의 [+ 지출] 판 모양, 예산 표에서 날 고르기 뒤 위치, 예산 없는 여행의 빈 상태, 지도 칸에 예산이 없는지.
