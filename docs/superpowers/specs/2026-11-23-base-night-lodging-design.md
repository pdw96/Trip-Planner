# 기준점을 "그날 밤 묵는 곳"으로 (#91)

2026-11-23 사용자 승인. 작은 변경(DB 변경 없음)이라 짧은 설계로 쓴다.

## 왜

기준점은 지금 "그날 나갔다 돌아오는 곳" 한 뜻이라, 동선이 늘 기준점 → 일정들 → 기준점 왕복으로 그려진다(#13 §5.5, `buildDayRoute` 가 앞뒤에 같은 기준점을 붙임). 실제 여행은 왕복인 날이 가운데 날뿐이다(사용자).

- 첫날: 집 → 부산 → 숙소 체크인 → … → 숙소 (도착하는 날)
- 마지막 날: 숙소 → … → 귀가 (출발하는 날)

지금은 첫날 "없음", 둘째 날 숙소, 마지막 날 "없음"으로 세 번 바꿔야 하고, 그러면 첫날 밤 숙소로 들어가는 구간을 잃는다. 숙소를 옮기는 날(A 체크아웃 → B 체크인)은 표현할 수 없다.

## 목표 / 하지 않는 것

- 목표: 기준점의 뜻을 **"그날 밤 묵는 곳"**으로 바꾼다. N일차 동선 = 전날 밤 숙소 → 그날 일정들 → 그날 밤 숙소. 첫날·마지막 날·숙소 옮기는 날이 손대지 않아도 맞게 그려진다.
- 하지 않는 것: DB 변경, [전체] 탭 "가까운 순 기준"(저장하지 않는 화면 상태, 기본값은 첫날 기준점 그대로), 숙소 장소를 지우면 앞 숙소가 이어지는 cascade(#13 사용자 결정 대기, 그대로).
- 실패로 볼 것: 지금 저장된 기준점이 새 뜻으로 읽었을 때 엉뚱한 동선이 되는 것. 운영 DB 의 기준점 행(여행 1개, 2박 3일: 1일차 A 숙소, 2일차 B 숙소, 3일차 없음)은 새 뜻으로 1일차 첫 일정 → A, 2일차 A → B, 3일차 B → 마지막 일정이 된다(사용자가 원하던 모양). 데이터 손볼 것 없음.

## 접근 (사용자가 고름: A)

| 안 | 내용 | 버린 이유 |
|---|---|---|
| **A** | **기준점 = 그날 밤 숙소. 시작점은 전날 밤 숙소, 끝점은 그날 밤 숙소** | — (DB 그대로, 첫날·마지막 날·숙소 옮기는 날 모두 저절로) |
| B | 기준점은 왕복 그대로, 첫날은 앞, 마지막 날은 뒤를 자동으로 뺌 | 숙소 옮기는 날이 여전히 왕복 |
| C | 날마다 쓰임새(왕복·출발만·도착만) 고르기 | `trip_bases` 칸 추가(마이그레이션), 고를 것이 늘고 숙소 옮기는 날은 여전히 안 됨 |

## 규칙

- 밤 숙소: N일차 밤 숙소 = `baseForDate(rows, N일차 날짜)`(저장 규칙 §5.5 그대로: 이 날부터 다음 행 전날까지).
- 여행은 N박 N+1일이다(`tripLengthLabel`). 밤은 첫날부터 마지막 날 **전날**까지.
- N일차 시작점 = 첫날이면 없음, 아니면 전날 밤 숙소.
- N일차 끝점 = 마지막 날이면 없음, 아니면 그날 밤 숙소.
- 당일치기(시작일 = 끝일)는 밤이 없어 시작·끝 모두 없음.
- "없음" 행 = 그날 밤 숙소 없음(야간 이동 등). 그 날은 마지막 일정에서 끝나고 다음 날은 첫 일정에서 시작한다.
- 같은 장소 합치기(`buildDayRoute`)는 그대로: 시작점이 첫 일정과, 끝점이 마지막 일정과 같은 장소면 한 점(체크인 일정 등). 시작점·끝점이 같고 일정이 없으면 한 점, 구간 없음.
- 시작점·끝점 모두 좌표가 없으면(30일 갱신 실패) 지금처럼 빠진다.
- 동선 계산은 지도 칸·일정 칸·하루 동선 Route Handler(`day-route-loader.ts`)가 같은 `routesByDate` 를 쓴다. Route Handler 는 한 날짜만 넘기므로 여행 시작일·끝일을 함께 넘겨 첫날·마지막 날을 판단한다.
- 구간 결과 저장소 키(`daySignature`)에 시작점·끝점을 모두 넣는다.

## 화면 (지도 N일차 탭)

```
2일차 밤 숙소 [🏨 B 호텔 ▾]  이 날부터 바뀌어요
아침엔 🏨 A 호텔에서 출발
```

- 이름표 "N일차 기준점" → **"N일차 밤 숙소"**. 고를 수 있는 것은 그대로 이 여행의 모든 장소(숙소 종류 위에, 친구 집·캠핑장도 고를 수 있게), 맨 위 "없음".
- 아래 한 줄 "아침엔 X에서 출발"은 시작점이 있을 때만(2일차부터, 전날 밤 숙소가 있을 때). 
- 마지막 날: 고르기 칸 없이 "아침엔 X에서 출발" 한 줄(시작점이 없으면 아무것도 없음).
- 당일치기: 고르기 칸 없음.
- 지도 핀: 시작점·끝점 숙소 핀을 둘 다(같으면 하나). 구간 목록·일정 사이 이동 줄·Google 길찾기 링크는 같은 구간을 쓰므로 함께 바뀐다.

## 빌더에게 남긴 것

- `DayRoute` 의 `base` 를 시작점·끝점 둘로 나누는 모양, `PanelDay` 에 넘길 값(밤 숙소 고른 값·아침 출발 장소·핀용 id).
- "아침엔 … 출발" 문구에 쓰는 장소는 저장된 값(서버) 기준. N일차 고르기를 바꾸면 N+1일차 문구가 서버 새로 그리기 뒤 바뀌는 것으로 충분하다.
