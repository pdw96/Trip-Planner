# 예산을 바텀 시트로 올리기 (#97)

2026-11-23. 작은 변경이라 짧은 설계로 쓴다. DB·서버 동작 변경 없음, 예산을 여는 방식만 바뀐다.

## 왜

사용자(2026-11-23, #88 배포 뒤): "누르면 예산 칸이 올라오는 느낌이면 좋겠어." #88 에서는 아래 예산 줄을 누르면 페이지가 맨 아래 예산 칸까지 내려간다. 원하는 것은 페이지는 그 자리에 두고 예산이 아래에서 올라오는 것.

- 목표: 아래 예산 줄을 누르면 예산 카드가 바텀 시트로 열린다. 닫으면 보던 화면 그대로다.
- 하지 않는 것: 예산 카드 안 내용·계산·양식 변경, 모임·개인 통장(#89), 새 주소.
- 실패로 볼 것: 같은 예산이 한 화면에 두 번 보이는 것(#88 을 연 이유), 시트를 닫았는데 페이지 스크롤 위치가 바뀌는 것, 내용을 스크롤하다 시트가 닫히는 것, 시트가 열린 채 초점이 뒤 화면으로 빠지는 것.

## 접근

- **A. `<dialog>` showModal + 쓸어내리기 직접 (고름).** 지금 [+ 지출] 시트와 같은 방식. 초점 가두기·Esc·닫은 뒤 초점 돌려주기를 브라우저가 하고, 두 시트 모양이 같다. 쓸어내리기만 직접 붙인다.
- B. 바텀 시트 라이브러리(vaul 등). 쓸어내리기가 매끄럽지만 새 패키지라 `package.json` 이 바뀌어 위험 경로가 되고, 이득이 그만큼 크지 않다.
- C. 직접 만든 판(div). 초점 처리를 새로 짜야 한다. A 보다 나은 점이 없다.

## 설계

```
[전체] ① ② ③               ← 위 날짜 줄 (시트가 열리면 흐려짐)
지도 / 가 볼 곳 / 일정        ← 맨 아래 예산 칸 없음
━━━━━━━━━━━━━━━━━━━━━━━━━━
2일차 예상 3만원 …  [+ 지출]  ← 늘 떠 있음. 요약을 누르면 시트

   (시트가 열린 모습)
┌──────────────────────────┐
│        ───  (손잡이)      │ ← 여기·날짜 줄을 잡고 내리면 닫힘
│ [전체] ① ②̲ ③        ✕  │ ← 시트 안 날짜 줄, 위에 붙음
│ 2일차 예산               │
│ 예상 3만원 · 실제 …      │ ← 지금 BudgetCard 그대로, 내용이 길면 이 안에서 스크롤
└──────────────────────────┘
```

1. **맨 아래 예산 칸을 없앤다(사용자).** 예산은 시트에서만 본다. #88 의 예산 칸 보임 감시(IntersectionObserver), 줄 숨기기(`hidden`·`inert`), 날 바꿀 때 위치 유지(`onBeforeSelect`·`useLayoutEffect`), 예산 칸 `h2`·`scroll-mt` 를 지운다. `onBeforeSelect` 는 `selected-day.tsx` 에서도 지운다(쓰는 곳이 예산 칸뿐).
2. **아래 줄은 늘 떠 있다(사용자).** 왼쪽 요약을 누르면 예산 시트가 열린다(지금의 "예산 칸으로 가기" 대신). 스크린 리더용 글은 "예산 열기"로 바꾼다.
   - [+ 지출] 은 그대로 둔다(Claude 판단: 지출을 바로 적는 가장 빠른 길). 지금처럼 따로 지출 넣기 시트를 연다.
   - **예산이 없는 여행(사용자 동의):** 지금은 줄이 없다. 줄 자리에 "예산 정하기" 한 줄을 띄우고, 누르면 예산 시트가 **설정 양식이 열린 채로** 열린다(Claude 판단: 한 번 덜 누르게).
3. **예산 시트(사용자).** `<dialog>` showModal. 휴대폰은 전체 폭, PC(`sm` 이상)는 [+ 지출] 시트처럼 `max-w-2xl` 가운데. 바탕은 흐리게. 닫기: 바깥 누르기·[✕]·Esc·아래로 쓸어내리기. 닫으면 페이지 스크롤·고른 날은 시트에서 마지막으로 본 그대로다.
   - 높이: 내용만큼, 최대 85dvh(Claude 판단). 넘치면 시트 안에서 스크롤하고 맨 위(손잡이·날짜 줄·✕)는 붙어 있다.
   - **시트 안 날짜 줄(사용자, ①):** 맨 위에 `[전체] ① ② ③`. 위 날짜 줄과 같은 고른 날(`useSelectedDay`)을 읽고 바꾼다. 시트에서 날을 바꾸면 뒤 화면도 그날이 된다. 모양은 위 날짜 줄과 같게(공통 부분은 빌더가 나눔). 날짜 표에서 날을 눌러도 시트는 열린 채 카드만 바뀐다.
   - 쓸어내리기: 손잡이와 날짜 줄 부분을 잡고 내릴 때만(Claude 판단: 내용 스크롤과 헷갈리지 않게). 손가락을 따라 시트가 내려오고, 일정 거리(또는 빠르게 튕김)를 넘으면 닫히고 아니면 제자리로 돌아온다. 동작 줄이기(`prefers-reduced-motion`)면 애니메이션 없이. 날짜 줄은 가로 스크롤도 되므로, 세로로 움직일 때만 쓸어내리기로 본다.
   - 시트 안 양식(설정·일정 밖 지출) 저장 뒤 시트는 열린 채 숫자만 새로 그려진다(서버 재검증 → props 갱신). 열 때마다 카드의 열린 양식은 닫힌 상태로 시작한다(설정 양식으로 여는 2번 경우만 예외).
4. **페이지 배치.** `BudgetSection` 은 article 마지막 그대로(줄이 sticky bottom 으로 끝까지 따라오게). 예산 칸이 없으니 줄은 일정 칸 뒤에 바로 온다.

## 빌더에게 남긴 것

- 파일 나눔(시트 컴포넌트, 날짜 칩 공통 부분), 쓸어내리기 문턱 값, 열고 닫는 애니메이션.
- 확인: 휴대폰·PC 폭에서 브라우저로 — 줄 요약 누르기(마우스·키보드) → 시트, 시트 안 날 바꾸기와 뒤 화면 연동, 날짜 표에서 날 고르기, 닫기 네 가지(바깥·✕·Esc·쓸어내리기), 닫은 뒤 스크롤 위치, 긴 [전체] 카드 스크롤, 예산 없는 여행의 "예산 정하기" → 설정 양식, 저장 뒤 숫자 갱신, [+ 지출] 시트, 다크 모드.
